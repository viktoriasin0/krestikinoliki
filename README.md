# krestikinoliki
# Руководство пользователя: Игра «Крестики-нолики»

## 1. Общее описание
Данная программа представляет собой классическую логическую игру «Крестики-нолики» для двух игроков, реализованную в виде оконного приложения. Игроки по очереди ставят свои знаки на поле размером 3x3. Цель игры — первым выстроить три своих знака в ряд (по горизонтали, вертикали или диагонали).

## 2. Запуск игры
Для начала игры запустите исполняемый файл программы (обычно `Form1.exe` или файл вашего проекта). Откроется главное окно игры

## 3. Элементы интерфейса
Окно программы состоит из следующих элементов:
*   **Игровое поле** — сетка из 9 квадратных кнопок (3 ряда по 3 кнопки), на которых игроки будут делать свои ходы.
*   **Индикатор хода** — текстовая надпись «Ход:» в нижней левой части экрана. Рядом с ней отображается символ текущего игрока (`X` или `O`).
*   **Статус игры** — пустая строка в верхней части окна (над игровым полем). В ней будут появляться сообщения о победе одного из игроков или о ничьей.
*   **Кнопка «Начать заново»** — кнопка в нижнем левом углу, которая сбрасывает текущую партию и очищает игровое поле.

## 4. Как играть
1.  При запуске программы игра автоматически начинается с хода игрока **«X»** (об этом сообщает индикатор «Ход: X»).
2.  Нажмите левой кнопкой мыши на любую пустую ячейку игрового поля, чтобы сделать ход. В выбранной ячейке появится ваш символ (`X` или `O`).
3.  После вашего хода эта ячейка станет неактивной (кнопка блокируется), чтобы исключить возможность повторного нажатия.
4.  Ход автоматически переходит ко второму игроку (индикатор сменится на «Ход: O» или наоборот).
5.  Игроки продолжают ходить по очереди до тех пор, пока один из них не победит или пока не закончатся свободные ячейки.

## 5. Условия победы и завершения игры
*   **Победа:** Если один из игроков выстроил три своих символа в один ряд (горизонтально, вертикально или по диагонали), игра немедленно завершается. В верхней части экрана появится сообщение: *«Игрок X выиграл!»* (или *«Игрок O выиграл!»*). Все кнопки на поле станут неактивными, чтобы предотвратить дальнейшие ходы.
*   **Ничья:** Если все 9 ячеек заполнены, но ни один из игроков не смог выстроить три символа в ряд, игра завершается ничьей. В верхней части экрана появится сообщение: *«Ничья!»*.

## 6. Начало новой игры
Чтобы сыграть еще одну партию, нажмите кнопку **«Начать заново»** в нижней части окна. 
*   Все ячейки очистятся и снова станут доступными для нажатия.
*   Строка статуса вверху исчезнет.
*   Первый ход снова будет принадлежать игроку **«X»**.

  *Примечание: Вы также можете начать новую игру в любой момент, даже если текущая партия еще не завершена.*
